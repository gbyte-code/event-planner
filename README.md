# Event Planner

## About

This is a small project for organizing an event, its tasks, and related information.

## Goal

The goal is to practice managing a project using Git and GitHub, including branches, commits, and pull requests.

## Main Files

- README.md — Project documentation
- tasks.md — List of project tasks
- event.md — Event information

## Contribution

To contribute:

1. Clone the repository.
2. Create a new branch for your changes.
3. Make your changes and commit them.
4. Push the branch to GitHub.
5. Create a Pull Request for review.
